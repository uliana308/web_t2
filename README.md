# Schedly — персональный организатор

Полонская Ульяна Викторовна, 4-МД-17. Дашборд. Макет под экран 1440 × 1024, шрифт Inter.

Виджеты: прогресс задач, календарь, точное московское время, встречи и связь,
оценка дня, цитата, погода. Каждый виджет можно добавить на панель только один раз.

## Архитектура

```
UIComponent
├── TaskProgressWidget, MeetingsWidget, AssessmentWidget, QuoteWidget
└── ApiWidget
    └── ClockWidget, CalendarWidget, WeatherWidget
```

## Источники данных

timeapi.io — `/api/Time/current/zone?timeZone=Europe/Moscow` 
date.nager.at — `/api/v3/PublicHolidays/{год}/RU` 
api.open-meteo.com — `/v1/forecast` 

Gismeteo в виджете погоды — только ссылка на подробный прогноз: их API требует личный токен,
а хранить секретный ключ в браузере нельзя, поэтому данные берутся из Open-Meteo.

## Доступность

- всё управление работает с клавиатуры, фокус виден;
- без мыши виджет можно переставить стрелками, если фокус стоит на ручке перетаскивания.

## Ограничения

- Данные (оценки, встречи, подключения) не сохраняются после перезагрузки.
- Статистика прогресса, план в календаре и встречи — демонстрационные данные.
- Без интернета часы показывают время устройства по UTC+3, календарь и погода показывают ошибку.
- Макет рассчитан на ноутбук 1440 × 1024, мобильной версии нет.
